# GLM-5.3에 이미지 검토 연결

## Skill과 MCP의 역할

Skill은 검토 순서·기준을 지시합니다. 이미지 인식 기능을 추가하지는 않습니다. MCP가 이미지 bytes만 반환하는 경우 text-only GLM-5.3이 이미지를 이해하게 되지는 않습니다. **도구 내부에서 별도 시각 모델을 호출하고 텍스트/JSON 분석 결과를 반환**하는 경로가 필요합니다.

MCP 서버가 로컬에서 실행된다는 것과 추론이 로컬에서 수행된다는 것은 별개입니다. 회사 자료는 회사가 허용한 시각 모델/서비스 경로로만 분석합니다.

## 현재 회사 적용 상태

사용자 확인(2026-11-03): 현재 회사에서는 Z.ai 방식 사용 불가. 외부 제공자 도메인에 대한 네트워크 통신 제한이 확인되었습니다. 별도의 허용된 API 경로가 있는지는 미확인입니다. 같은 차단 도메인을 같은 통신 경로로 호출하는 API로 바꾸는 것만으로 해결된다고 가정하지 않습니다. **아래 Z.ai 정보는 공개 문서 조사 기록이며 현재 적용 경로가 아닙니다.** 해당 연결을 기본값으로 설치·호출하지 않습니다.

실제 사용 가능한 시각 분석 수단이 확인되면 공급자와 무관한 아래 입출력 계약으로 연결합니다. 확인 전에는 NOT REVIEWED이며 현재 Kit의 나머지 검증은 진행할 수 있습니다.

## 공개 공식 도구 조사 기록 — 현재 사용 불가

[Z.ai Vision MCP Server 공식 문서](https://docs.z.ai/devpack/mcp/vision-mcp-server)는 OpenCode 설정을 제공하며 다음 도구를 나열합니다.

| 도구 | PPT QA에서의 활용 제안 |
|---|---|
| image_analysis | 전체/영역별 가독성·잘림·배치 검사 |
| extract_text_from_screenshot | 보이는 문구 추출 후 expected_text와 대조 |
| ui_diff_check | 같은 영역의 원본/결과 비교 보조 |
| understand_technical_diagram | 하단 구조도의 의미·연결 관계 확인 |

위 활용은 이 프로젝트의 제안입니다. 특히 ui_diff_check는 UI용이므로 PPT 적합성을 합성 테스트로 확인해야 합니다. 설치한 버전의 실제 `tools/list` 스키마를 읽고 호출하십시오. 이 문서는 가상의 도구 인자 이름을 공식 스키마라고 주장하지 않습니다.

공식 제공 형태는 GLM Coding Plan 인증, Node.js 22+, `@z_ai/mcp-server`, `Z_AI_API_KEY`/`Z_AI_MODE`를 사용합니다. **회사 GLM 사용 권한이 공식 외부 서비스 권한을 포함한다고 가정하지 않습니다.** 실제 연결 설정은 회사 승인 환경에만 저장합니다. 이 저장소는 API Key 또는 운영 MCP 설정을 포함하지 않습니다.

## 권장 호출 순서

1. MCP 연결과 실제 이미지 분석 tool 노출을 확인합니다.
2. 정상 이미지·제목이 잘린 합성 이미지·사진 프레임이 변한 합성 이미지를 분석하여 결함을 구분하는지 확인합니다.
3. 원본/결과를 같은 렌더러·크기로 준비합니다. 전체 slide와 영역별 crop을 제공합니다. 의도된 문구/사진 교체는 diff 예외로 설명합니다.
4. 한 영역씩 잘림·overflow·겹침·crop·정렬·간격·그림자·테두리·위계·원본 구조를 질문합니다. 명확하지 않으면 NOT REVIEWED를 반환하게 합니다.
5. 응답 원문, 도구명, 실제 provider/model 정보(확인 가능 시), 입력 이미지 해시, 실행 성공/실패를 회사 로컬에 기록합니다.
6. FAIL 또는 미확인이 있으면 수정합니다. 후보가 변경되면 edit 이후 gate를 재실행합니다.
7. 실제 분석에 근거해서만 visual_qa.json에 체크·reviewer·notes를 기록합니다. 일반 설명 한 줄을 모든 항목 PASS로 변환하지 않습니다.

공식 MCP 응답이 Kit 형식과 다르면 별도 adapter가 필요합니다. v0.1은 이 adapter나 MCP 서버를 구현하지 않았습니다. 실제 tools/list 및 회사 승인 서비스가 확인된 후 연동합니다.

## 사내 MCP를 만드는 경우의 제안 계약

도구 이름 예시 `review_ppt_region`은 공식 도구명이 아닙니다. 입력: 원본 crop, 결과 crop, expected_text, 허용된 차이, region id. 서버가 허용 폴더의 이미지 파일을 읽고 승인된 시각 모델에 전달합니다. 응답: 각 체크의 PASS/FAIL/NOT REVIEWED, 구체적 발견 내용/위치, 도구 실행 id, provider 정보, 두 입력 해시. MCP `isError`이면 검토 미수행입니다. 반환 JSON은 TextContent로도 제공하여 텍스트 모델이 읽을 수 있게 합니다.

[공식 MCP Python SDK media 설명](https://py.sdk.modelcontextprotocol.io/servers/media/)은 이미지 콘텐츠 반환과 분석 결과가 다름을 확인할 수 있는 자료입니다. 이 Kit은 이미지 해시와 crop 일관성만 자동 확인하며 시각 모델의 오판 가능성을 제거하지는 않습니다.

## 외부 endpoint가 차단된 경우

프록시/WAF 정책을 우회하지 않습니다. 우선순위는 (1) 사내 승인 멀티모달 모델 서비스, (2) 허용된 사내 중계 endpoint가 실제 이미지 입력을 지원하는 경우, (3) 회사가 허용한 로컬 비전 모델입니다. 어느 것도 없으면 사람 검토로 QA를 수행합니다. 단순 로컬 MCP 설치는 추론 서버의 외부 호출 제한을 해결하지 못합니다. OCR만 가능하면 텍스트 보조 검사로 활용하되 그림자·레이어·디자인 비교까지 통과한 것으로 처리하지 않습니다.
