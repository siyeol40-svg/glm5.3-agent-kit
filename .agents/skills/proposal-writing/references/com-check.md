# COM 연결과 확인 범위

처음 연결할 때만 `scripts/Probe-ProposalEnvironment.ps1 -TargetName <정상 UI로 열린 작업 문서>`로 읽기 전용 연결을 확인합니다. 다른 인스턴스/문서를 임의로 열거나 변경하지 않습니다. 읽기 성공은 편집·저장·회사 DLP 호환 성공이 아닙니다.

현재 객체에서 조회되는 텍스트·좌표·서식·글자 경계·회전·자동맞춤 속성만 검사 근거로 사용합니다. 설정 글자 크기만으로 자동축소 후 표시 크기를 확정하지 않습니다. 실제로 읽힌 최소 크기 위반은 실패이며 회전/자동맞춤 상태의 경계는 일반 비회전 상자와 단순 비교하지 않습니다. 조회되지 않는 값은 확인불가로 남깁니다.

제작 도구는 텍스트 할당 전 자동맞춤을 끄고 서식 적용 뒤 상자 크기를 고정합니다. 실수형 COM 인자는 Single, 인덱스는 Int로 고정합니다. 생성물의 회전·자동축소를 금지하고 원문·좌표·색·글자 경계·겹침을 현재 객체에서 재조회합니다.

기존 그림/설명도는 같은 문서의 선언된 객체만 복사할 수 있습니다. 현재 보이는 프레임을 유지하며 원본 이미지 비율이나 실제 내용이 옳다고 판정하지 않습니다. 이미지 의미·그룹 내부 가독성·픽셀·미학은 부분확인/미검증입니다.

회사에서 새 파일도 즉시 DLP 대상입니다. 스크립트·JSON·로그의 실제 허용 여부는 회사 안에서 확인합니다. 실패 시 실행 정책 우회·디스크 파싱·새 서버·다른 이미지 모델을 대체 경로로 쓰지 않습니다.
