# 개선 사항

근거로 여섯 조치를 두 역할로 나눌 수 있으면 [V10 역할별 개선 사항](v10/actions.md)과 그 빈 양식을 사용합니다. 그룹은 역할 구분이며 적용 순서가 아닙니다.

새 실행은 [넓은 조치 카드 V8](v8/actions.md)와 context가 지정한 현재 단계 자료만 읽습니다. 여섯 조치마다 근거가 있는 본문3개·효과1개·등록된 icon을 확보했을 때 `layout_profile:"reference-v8-actions"`와 [V8 빈 틀](../assets/stage-inputs/v8/actions.json)을 사용합니다. 최소18항목을 유지하며 빈 칸을 임의 조치로 채우지 않습니다. V8은 3열×2행 고정 카드이며 좌표를 작성자가 고르지 않습니다. 미래 단계·전체 코드·완성 예시·QA 이미지/평가 답을 읽지 않습니다.

기존 V6 실행이나 명시적으로 세로 여섯 카드를 선택한 경우 [V6 개선 사항](v6/actions.md)과 [V6 빈 틀](../assets/stage-inputs/v6/actions.json)을 유지합니다. 자료 부족을 profile 변경으로 숨기지 않으며 이 단계는 V7로 바꾸지 않습니다.

기존 V2/V3/V4 실행은 원래 profile의 현재 단계 규약을 유지하되 최신 분량 합격선은 동일하게 검사합니다.
