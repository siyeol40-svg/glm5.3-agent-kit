# 효과 파악 · 실적과 해석 조건

[공통 규칙](common.md) 뒤 `assets/stage-inputs/v6/effects.json`을 채웁니다. 순서는 outcomes/metrics, details/table 또는 bullets, operation/bullets, boundary/bullets 네 개입니다.

핵심 지표는 한~세 개, 표는 서로 다른 비교·운영 지표, operation은 실제 운영 결과, boundary는 전망/정성 비교/적용 조건을 구분합니다. 최소15항목이며 같은 숫자를 표와 카드에 반복해도 한 번만 셉니다. details가 bullets이면 문장마다 line_states가 필요합니다.

예상 수명과 실제 운전 성과, 수질 기준과 발표된 농도 상한, 기술상 가능 회수율과 실제 회수율을 섞지 않습니다. 미공개 비용이나 시간당 가치를 넣어 절감액을 만들지 않습니다. 정성 효과는 정성 그대로 씁니다. 막연한 ‘확인 필요’로 빈 공간을 채우지 않습니다. 제목과 결론은 실제 자료의 범위를 넘지 않아야 합니다.
