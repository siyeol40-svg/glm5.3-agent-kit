# 개선 사항 · 여섯 조치 카드

[공통 규칙](common.md) 뒤 `assets/stage-inputs/v6/actions.json` 하나를 채웁니다. action/bullets 카드 정확히 여섯 개입니다. 순서·제목·지원 icon·근거·lines·outcome(목적)이 필요합니다.

각 카드에 서로 다른 짧은 본문을 넣어 전체18항목 이상을 담습니다. 보통 카드마다 세 문장입니다. 구현 내용/적용 조건/공정 원리를 구분하며 같은 목적을 바꿔 반복하지 않습니다. 일반 원리를 설명하는 카드는 제목이나 부제로 그 범위를 밝힙니다. 실제 조치가 부족하면 효과 수치나 미확인 정비행위를 옮겨 채우지 않습니다.

한 카드 폭은145pt입니다. 제목은 짧게, 본문은 약 두~세 줄에 들어가는 문장으로 씁니다. 목적은 본문의 복사가 아닌 한 문장입니다. outcome·제목·아이콘은 분량에 세지 않습니다. 카드는 번호가 있는 독립 조치 목록이며 화살표로 강제 연결하지 않습니다. 일반 원리를 별도 직렬 설비나 시간 순서로 오해하게 하지 않습니다. validate가 실패하면 원문 조건을 보존해 정리합니다.
