# 원인 분석 · 구조와 근거를 연결

[공통 규칙](common.md)을 읽은 뒤 `assets/stage-inputs/v6/cause.json` 하나만 채웁니다. 네 패널 순서가 고정입니다.

1. system/bullets: 계통의 구성과 역할. 짧은 문장과 지원 icon.
2. evidence/table: 원인 판단에 필요한 관측·조건. 원문에 없는 장애 로그를 만들지 않습니다.
3. causal/flow 또는 bullets: 근거와 연결된 흐름/판단. 가설이면 line_states=hypothesis로 표시하고 입증됐다고 쓰지 않습니다.
4. boundary/bullets: 적용 조건과 분석 경계. 막연한 미공개 목록으로 분량을 채우지 않습니다.

최소15항목입니다. 구조4/표5/흐름4/조건3 정도를 담을 수 있으나 근거와 서로 다른 의미가 먼저입니다. 일반 기술 원리와 특정 현장의 실제 원인을 구분합니다. 본문을 비교적 짧게 유지하며 표는 내용에 맞는 열 수를 선택합니다. 현재 단계 validate 결과만 확인하고 다음 단계로 갑니다.
