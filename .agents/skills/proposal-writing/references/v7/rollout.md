# 횡전개 · 계획 Gate

[공통 규칙](common.md)과 [현재 빈 양식](../../assets/stage-inputs/v7/rollout.json)만 읽습니다. `scope:"proposal"`의 검토안만 지원합니다. 패널 순서는 `coverage/table` 5행2열, `expansion/flow` 4활동, `checks/bullets` 6문장, `acceptance/bullets` 6문장으로 최소21항목을 유지합니다. 실제 일정·완료 상태·진도율을 넣지 않습니다.

`visuals.kind:"gate_board"`이며 `check_gates`와 `acceptance_gates`는 각각6개의 정수0~3입니다. 각 값은 같은 위치의 확인/판정 문장이 연결될 `expansion.steps` 번호입니다. 도해의 Gate 표시는 사람이 읽는1~4번이며 입력 번호0~3과 구분합니다. 빈 양식의 `null`은 미지정이므로 각 문장의 실제 역할을 보고 채웁니다.

네 활동은 조사, 설계·안전, 시험 범위·책임 승인, 검증 후 표준화 판단을 구분합니다. 조사항목은 필요한 조사/설계 Gate에, Commissioning 결과의 판정은 검증 후 Gate에 연결합니다. 시험 범위의 승인을 시험 결과의 확인처럼 매핑하지 않습니다. 같은 Gate에 여러 문장이 연결될 수 있으며 배열을 예시에서 복사해 일괄 배정하지 않습니다.

네 활동의 순서는 계획이며 실적이 아닙니다. 대상5개·확인/판정12개·활동4개를 반복 요약으로 부풀리지 않습니다. 도구가 부제에 ‘검토안·적용 실적 아님’ 표식을 추가하므로 입력 subtitle에는 반복하지 않습니다. 미공개 단가·확대 대수·확정 날짜·성과를 만들지 않습니다. 실제 확대 실적은 이 V7 구성이 지원하지 않으며 근거가 있으면 V6 지원 범위를 확인합니다.
