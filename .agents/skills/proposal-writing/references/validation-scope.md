# v1의 지원 범위와 실제 확인

**현재 판정: v1 레퍼런스 시각 품질 미달, 수정 중.** 최초 완료 보고 전에는 실제 출력의 시각 QA를 하지 않았습니다. 이후 개인 공개 PVAC 슬라이드 5장을 처음 확인했을 때 큰 빈 공간·문구 반복·단어 중간 줄바꿈을 발견했습니다. 기존 시험 통과 기록을 디자인 완성으로 사용하지 않습니다. 수정본도 실제 출력 비교 전에는 합격이 아닙니다.

Codex가 개인 PC의 기존 PowerPoint16.0, PowerShell7.6.5에서 시험했습니다. GLM 호출은 하지 않았습니다. 회사의 DLP 프로그램·권한·폰트·실행기를 복제한 시험은 아닙니다.

## 지원하는 작업
- 문제 현상 → 원인 분석 → 개선 사항 → 효과 파악 → 횡전개를 순서대로 작성합니다. 정해진 패널 수와 글머리·흐름·시간 흐름·표·지표·막대만 선택합니다.
- 근거·수치·설비 식별자를 등록하고 현재 단계만 처리합니다. 자료 부족·모순·지원하지 않는 배치는 멈추며 숫자·실적·사진을 만들지 않습니다.
- 같은 문서의 선언된 그림/설명도 객체를 복사해 현재 프레임의 비율을 유지합니다. 이미지를 새로 생성·검색·내보내지 않습니다.
- 도구가 만든 객체의 원문·좌표·서식·글자 경계·겹침·자동맞춤·회전·완료 상태를 검사합니다. 동일 내용의 지원 native 객체만 제자리에서 복원하고 다시 검사합니다.

## 실제 확인한 것
공개 반도체 PVAC 정비와 드라이 펌프 절전 사례로 각각5장을 제작했습니다. 지원하는 비시각 검사 항목은 실패 없이 통과했고, PowerPoint에서 저장한 뒤 열린 현재 객체를 다시 검사했습니다. 글자 넘침을 잡아 동일 SlideID의 객체를 수정한 시험, 그룹/표의 제한된 읽기, 설명도 복사와 저장 후 재조회도 수행했습니다. 실제 사진 복사는 아직 시험하지 않았습니다.

## 개인 개발 검수와 회사 실행의 구분
Codex는 개인 공개 예시의 실제 출력 이미지를 레퍼런스와 비교해 디자인을 검수합니다. 회사에서 실행하는 제작·QA 도구에는 자동 캡처·렌더·look_at을 넣지 않습니다. 개인 시각 검수의 성공을 회사가 화면을 자동 판독한 것으로 보고하지 않습니다.

## 아직 증명하지 않은 것
수정본의 시각 품질·사진 의미·폰트 대체·인쇄 충실도, 회사 DLP/스크립트·JSON 입출력, 회사 GLM의 짧은 요청 해석과 도구 사용, 사용자 UI 재열기 후 상태는 미검증입니다. PowerShell5.1은 개인 PC 실행 정책에 막혀 실제 실행 호환을 확인하지 못했습니다. 기존 허용 런타임이 없거나 Add-Type/COM 연결이 막히면 설치·정책 우회 없이 멈춥니다.

`pass_with_limitations`는 지원한 비시각 항목의 결과입니다. 실제 화면을 보았거나 모든 디자인을 검증했다는 뜻이 아닙니다.
