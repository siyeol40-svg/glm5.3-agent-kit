# 횡전개

대상5개·계획 활동4개·확인6개·판정6개를 준비할 수 있는 검토안이면 [V7 계획 Gate](v7/rollout.md)와 그 빈 틀을 사용합니다. 각 확인·판정 문장을 담당 Gate에 직접 연결합니다. 계획을 실제 적용·완료·진도율로 표현하지 않습니다.

구조가 맞지 않거나 근거가 있는 실제 확대 실적을 다루면 [V6 횡전개 틀](v6/rollout.md)의 지원 범위를 확인해 `reference-v6`를 명시적으로 선택합니다. 최소21항목을 유지하며 미공개 대상·일정·성과를 만들지 않습니다. 선택한 현재 leaf와 context의 자료만 읽으며 미래 단계·전체 코드·완성 예시·QA 이미지/평가 답은 읽지 않습니다.

기존 V2/V3/V4 실행은 원래 profile의 현재 단계 규약을 유지하되 최신 분량 합격선은 동일하게 검사합니다.
