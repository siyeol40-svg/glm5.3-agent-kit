# 문제 현상

사실 ID 목록이 준비됐고 근거 표와 일반 절차를 함께 쓸 때는 [절차형 작성 양식](v5/procedure-brief.md)을 사용합니다. 이 경로의 현재 단계 지침은 그 파일 하나입니다.

그 외 새 실행은 [복합 문제 현상](v5/problem.md) 하나와 context의 현재 단계 자료만 읽습니다. `layout_profile:"reference-v5-problem"`과 [V5 빈 틀](../assets/stage-inputs/v5/problem-dense.json)을 사용하고 최소18항목을 충족합니다. 이 단계는 V7로 바꾸지 않습니다. 미래 단계·완성 예시·과거 로그·검수 자료를 제작 입력으로 읽지 않습니다.

기존 V2/V3/V4 실행은 원래 profile의 현재 단계 규약을 유지하되 최신 분량 합격선은 같습니다.
