# V4 개선 사항

먼저 [공통 입력](common.md)을 읽고 [현재 빈 틀](../../assets/stage-inputs/v4/actions.json)만 채웁니다. 실제 조치 수에 맞는 세~여섯 카드만 씁니다. 모든 카드는 role:action,kind:bullets입니다. 세 개 미만이면 수를 만들지 말고 지원 불가로 멈춥니다.

각 카드에 짧은 조치명, 실제 내용, 근거 있는 짧은 outcome과 [도해 목록](glyphs.md)의 icon을 넣습니다. outcome은 본문 반복 대신 목적입니다. 시행 완료·진행·예정을 구분하고 병렬 조치에 임의 일정·선후관계를 만들지 않습니다. 아직 측정하지 않은 효과를 실적으로 쓰지 않습니다.

긴 문장은 사실을 보존해 줄입니다. 카드 너비·글자·여백·자동맞춤을 바꾸지 않습니다. validate 뒤 render -StageId actions를 실행합니다. 적용 상태·실제 검사·남은 자료만 짧게 보고합니다.
