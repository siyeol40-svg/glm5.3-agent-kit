# 설명용 도해 선택

bullets의 icon, flow의 step_icons만 선택합니다. step_icons는 steps와 같은 길이의 배열입니다. 정확한 소문자 문자열만 씁니다.

기본: heat_exchanger|oil|water|microbe|clean|training|rotation|shield|monitor|check|cost|factory
V4 추가: vacuum_chamber|part|erosion|material|energy|tank|filter|membrane_stack

실제 대상에 맞는 장비·부품·현상 도해를 고릅니다. factory는 공장 범위에만 사용하며 모든 부품을 공장으로 대신하지 않습니다. 도해는 설명용 고정 도형이고 실제 상태·고장·측정 증거가 아닙니다.
