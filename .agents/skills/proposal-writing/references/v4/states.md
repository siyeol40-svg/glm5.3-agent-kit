# 줄마다 근거 상태를 나눌 때만

현재 단계 leaf가 허용한 bullets에만 line_states를 넣습니다. 필수인지 선택인지는 현재 leaf를 따릅니다. 필수인 경우 누락·null·빈 배열을 허용하지 않습니다. lines와 같은 순서·길이의 배열이며 정확한 문자열 supported|hypothesis|unknown|boundary만 씁니다. 각각 자료기반·가설·추가확인·적용범위로 표시합니다. 모델이 업무 원자료를 바탕으로 판단하고 기존 패널 source_ids를 유지합니다. supported는 해당 자료에 근거를 둔 판단이며 독립 검증이나 원인 입증을 뜻하지 않습니다. 선택 입력일 때만 생략 후 무분류 표시를 허용합니다. 다른 위치·비배열·다른 값은 거부합니다.

효과의 글 목록은 현재 고정 구성에서 최대 네 줄을 지원합니다. 상태가 세 종류 이상이거나 같은 상태가 네 줄이면 숫자 카드와 분류 행을 함께 쓰는 압축 구성을 자동 선택합니다. 다섯 줄 이상이나 이 압축 구성에 별도 계산 패널까지 넣는 조합은 제작 전에 거부합니다. 중요한 제한을 삭제하거나 자동 글자 축소로 밀어 넣지 않습니다.
