# V4 공통 입력

현재 단계의 업무 사실·허용된 원본 참조·COM 측정값만 읽습니다. 승인된 원문 읽기 결과의 서명·참조와 원장 내용을 대조하며 연결 성공이나 요약만으로 원문 정합성을 통과시키지 않습니다. `layout_profile:"reference-v4"`를 쓰고 현재 단계의 빈 틀 하나만 채웁니다. 좌표·색·폰트·계약 밖의 키를 추가하지 않습니다. 기존 V2/V3 실행은 원래 profile과 입력을 유지합니다.

[필수 분량 합격선](../content-density.md)을 유지합니다. 간결형의 과거 통과는 최신 분량 통과가 아닙니다. 제목·장식·반복·자료 없음으로 채우지 말고, 틀이 하한을 담지 못하면 미완료로 보고합니다.

bullets.lines는 한~여섯 줄, flow.steps는 두~네 단계입니다. 모든 패널에는 역할에 맞는 title,kind,source_ids를 넣고 선택 tone은 normal|danger|success만 씁니다.

모든 단계에는 짧은 citation과 비가상 사실 source_ids가 필요합니다. citation은 출처 원장을 대신하지 않습니다. 수치·기간·설비 식별자는 등록한 [[ID]]로만 표시합니다. 파생 수치를 표시하면 그 입력 출처를 단계와 해당 패널에 모두 연결합니다. 페이지 제목은 업무 주장, 패널 제목은 짧은 명사구로 씁니다. 빈 문구·제작 설명·중복 outcome으로 지면을 채우지 않습니다.

현재 단계 validate 뒤 지정된 열린 문서에만 render합니다. 회사 규칙과 허용된 원문 읽기 범위를 지키며 새 API·설치·서버·Office 직접 읽기·자동 캡처/렌더/look_at을 추가하지 않습니다. 실제 검사를 실행한 범위만 보고하고 회사 호환·시각 품질을 확대해서 말하지 않습니다.

조립 전 제목·문구·모든 표 열·수치·제한 설명이 남는지 검사합니다. REFERENCE_CONTENT_LOSS는 미지원 조합의 내용 누락 위험, TEXT_NEEDS_SHORTEN은 공간 초과이므로 성공이 아닙니다. 사실과 제한을 보존해 정리하거나 지원되는 구성을 선택합니다. 전역 문구 존재 검사만으로 연결 의미까지 확인한 것은 아닙니다. 실패·확인불가면 다음 단계를 중단합니다. 미지원 조합을 새 배치로 대신하지 않습니다.
