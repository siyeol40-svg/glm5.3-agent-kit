# 회사 표기 · English 용어·수식어와 한국어 설명

설비·공정·부품·물질·지표의 전문 명사는 영어로 쓰고 조사·동사·설명은 자연스러운 한국어로 씁니다. 예: `Local Scrubber의 Wastewater를 분리해 Reclaim한다`, `Filter와 잔류 Chlorine을 병용한다`. 문장 전체를 억지로 영어로 바꾸거나 통상 쓰지 않는 영어 명사를 만들지 않습니다. 고정된 페이지 이름(문제 현상/원인 분석 등)은 유지합니다.

기본 용어는 assets/terminology-policy.json의 고정 사전을 사용합니다. 처음 등장하는 낯선 약어는 짧게 풀어 쓸 수 있으며 그 뒤 같은 이름을 유지합니다. 같은 문서에서 Filter/필터처럼 혼용하지 않습니다. 임의 번역으로 설비·성분·공정의 뜻을 바꾸지 않습니다. Wafer, Local Scrubber, Process, System, Filter, Feedwater, Recovery, Service Life 등 업무에 익숙한 표현을 우선합니다.

표의 지표명·카드 지표명·숫자 원장의 metric은 함께 맞춥니다. source_ids·실제 값·부등호·전망 조건은 번역으로 바꾸지 않습니다. 원문 근거 원장은 원래 언어 그대로 보존하며, 번역된 업무 본문만 검사합니다. 영어 명사가 길어지면 정해진 약어/동일 의미의 짧은 문구로 정리합니다. 글자 축소·임의 좌표·조건 삭제로 해결하지 않습니다.

도구의 용어 검사는 고정 사전의 한국어 전문용어 혼입을 찾아 수정 요청합니다. 모든 한국어 명사를 판별하는 기능은 아니므로, 모델도 현재 단계 문구를 검토합니다. 업무 본문에 검수 의견·점수·수정 이유를 넣지 않습니다.

영어 형용사·수식어도 개수 제한 없이 사용합니다. `High Temp.`, `Low OPEX`, `Small Footprint`, `Stable Operation`, `Existing HFW System`, `Integrated Process`, `General EDR`처럼 명사와 자연스럽게 묶습니다. 영어 형용사를 조금만 쓰거나 반드시 한국어로 남겨야 한다는 제한은 없습니다. 의미·근거·원문 조건은 그대로 보존합니다.
