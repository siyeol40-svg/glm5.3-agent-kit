# 넓은 조치 카드 V8

현재 단계 자료와 이 파일만 읽습니다. `reference-v8-actions`는 여섯 조치를 3열×2행으로 배치하는 명시적 변형입니다. V6의 여섯 세로 카드와 별도로 선택하며, 코드·좌표·폰트를 다시 작성하지 않습니다.

[현재 빈 양식](../../assets/stage-inputs/v8/actions.json)을 복사합니다. 각 조치는 `role:action`, `kind:bullets`, 짧은 제목, 원문에 근거한 서로 다른 본문3개, 효과1개, 등록된 icon과 직접 source_ids를 갖습니다. 여섯 조치의 의미 항목은18개 이상이며 제목·장식·중복·자료 없음으로 채우지 않습니다. 자료가 모자라면 확인 질문이나 미완료 상태로 남기고 조치를 발명하지 않습니다.

각 카드의 `icon:null`은 [조치의 뜻에 맞는 등록 도해](action-icons.md)로 직접 지정합니다. 제목의 주제와 맞는 값만 사용하며 기본 Filter 도해를 전 카드에 복사하지 않습니다. 도구는 명백한 주제 불일치를 제작 전에 차단하지만 의미·미학 전부를 보증하지는 않습니다.

업무 명사·형용사는 익숙한 영어를 사용하고 조사·동사는 자연스러운 한국어로 연결합니다. 넓어진 카드에서도 한 문장은 간결하게 씁니다. 숫자는 단일 `[[ID]]` 원장 연결을 보존하며 원문 단위·미만·초과·전망·범위 조건을 바꾸지 않습니다. 일반 원리를 현장 실적으로 주장하지 않습니다.

먼저 현재 단계 `validate`, 통과한 입력만 `render`합니다. 글자가 넘치면 근거와 조건을 보존해 문구를 줄이거나 지원 범위를 다시 확인합니다. 본문11.5pt/세부11pt/출처10pt 아래 축소·자동맞춤·회전은 허용하지 않습니다. 최종 화면을 봤다고 보고하지 않습니다.

회사에서는 정상 UI로 열린 지정 PowerPoint의 active COM만 사용합니다. Office 직접읽기·자동 Open·새 앱·새 API/MCP/서버·자동캡처·이미지/PDF export·look_at을 추가하지 않습니다. 개발 시각평가·QA이미지·검수정답·점수는 제작 입력과 업무PPT에 넣지 않습니다. 이 변형의 제작 성공이 GLM 실사용·회사 DLP 호환·98점 달성의 증거가 되지는 않습니다.
