# 조치의 뜻과 맞는 개념 도해

`icon`은 임의 장식이나 실제 현장 사진이 아닙니다. 각 조치 제목이 나타내는 대상·작동을 골라 아래 등록된 개념 도해를 지정합니다. 빈 양식의 `null`은 미지정이며 그대로 제작할 수 없습니다. 모든 카드에 같은 기본 도해를 복사하지 않습니다. 같은 주제의 조치라면 같은 도해를 쓸 수 있지만 각 제목과 뜻이 맞아야 합니다.

| 등록값 | 제목이 설명해야 하는 주제 |
|---|---|
|`factory`|Fab·Facility·Reclaim·Wastewater·Load·Process|
|`clean`|Chlorine·Chlorination·CIP·Cleaning|
|`filter`|Filter·Cartridge·Pretreatment|
|`membrane_stack`|EDR·Membrane·Ion·Desalting·Cation·Anion|
|`tank`|Tank·Return·Recycle·Feedwater·Blending·Supply|
|`rotation`|Polarity Reversal·Self-cleaning·Rotation|
|`water`|Water·Feedwater·NEWater·Cooling|
|`microbe`|Biogrowth·Biofouling·Microbe·Organic|
|`heat_exchanger`|Heat·Cooling·Cooler·Chiller|
|`oil`|Oil·Lubricant·Lubrication|
|`training`|Training·Education·Operator|
|`shield`|Safety·Interlock·Protection|
|`monitor`|Monitor·Sensor·Alarm·HMI·Control·Pressure·Temperature|
|`cost`|CAPEX·OPEX·Cost·Economics|
|`check`|Validation·Verification·Test·Qualification·Check|
|`vacuum_chamber`|Vacuum·Chamber|
|`part`|Part·Component·Robot·Actuator|
|`erosion`|Erosion·Wear·Corrosion|
|`material`|Material·Coating·Ceramic·Alloy|
|`energy`|Energy·Power·Electric|

도구는 제목의 제한된 의미 표지로 명백한 불일치를 차단합니다. 본문 어딘가에 Filter가 있다는 이유로 Ion 분리 제목에 Filter 그림을 고르지 않습니다. 규칙을 통과하려고 제목의 실제 뜻을 바꾸거나 원문에 없는 대상을 붙이지 않습니다. 맞는 도해가 없으면 미지원으로 남기고 지원 구성을 확인합니다. 이 검사는 깊은 의미 판단·이미지 판독·미학 품질을 보장하지 않습니다.
