# 원인 분석

현재 자료가 일반 EDR의 선택막·Water 유로·Ion 이동을 뒷받침하면 [V7 기전 도해](v7/cause.md)와 그 빈 틀을 사용합니다. `visuals.feature_indices`로 네 설명을 해당 도해 요소에 연결합니다. 실제 설비 배치도나 현장 원인 입증으로 표현하지 않습니다.

다른 장비에서도 표의 위치 근거와 입증된 단계 연결을 제시할 수 있으면 [V9 근거 연결](v9/cause.md)을 사용합니다. 근거가 충분한 연결을 잡을 수 없으면 [V6 구조·근거 틀](v6/cause.md)의 지원 범위를 확인해 `reference-v6`를 명시적으로 선택합니다. 근거와 최소15항목이 부족하면 필요한 자료를 묻고 미완료로 둡니다. 도구가 자동으로 profile을 대체하는 것은 아닙니다. 선택한 현재 leaf와 context의 자료만 읽으며 미래 단계·전체 코드·완성 예시·QA 이미지/평가 답은 읽지 않습니다.

기존 V2/V3/V4 실행은 원래 profile의 현재 단계 규약을 유지하되 최신 분량 합격선은 동일하게 검사합니다.
