# 숫자가 섞인 이름

설비·모델명에 숫자가 있을 때만 읽습니다. 수량은 `numbers`, 이름은 선택 원장 `identifiers:[{id,value,source_ids:[]}]`로 구분합니다. 생략과 빈 배열은 같습니다.

ID는 영문자로 시작하는 영문자·숫자·밑줄·하이픈의 최대 육십사 자이며 출처·수치 ID와 겹치지 않습니다. `I` 접두사는 예시일 뿐 필수가 아닙니다. value는 공백 없는 마흔 자 이내 이름이며 문자와 숫자가 각각 있어야 합니다. 마침표·밑줄·하이픈도 허용합니다. 통화·퍼센트·원/년/건/대 같은 수량 단위를 붙인 값을 이름으로 위장하지 않습니다.

이름은 인용한 source.text에 대소문자까지 같은 독립 토큰으로 있어야 합니다. 긴 이름의 일부가 같다고 근거가 되지 않습니다. 원문에 없는 별칭을 만들지 않습니다.

정확한 이름 뒤에 `을·를·은·는·이·가·의·와·과·로·으로·에·에서·부터·까지·에게` 등 고정된 조사나 `이다·입니다`가 붙은 한국어도 인정합니다. 조사·서술어 뒤에는 공백·문장 끝·문장부호 경계가 있어야 합니다. 예를 들어 `AC-50을 설명한다`, `AC-50입니다.`는 이름의 근거가 되지만 `AC-500`, `XAC-50`, `AC-50X`, `AC-50을X`는 인정하지 않습니다. 임의의 한국어 꼬리나 더 긴 모델명의 일부를 허용하는 규칙은 아닙니다.

제목·본문·흐름·표·자산 설명에는 `[[I1]]`로 참조합니다. metrics와 bars의 값은 계속 수치 원장의 `[[N1]]`만 사용하며 수량 표의 metric 연결도 유지합니다. 출처에 이름이 있다는 검사와 그 설비의 실제 성능·사진이 맞는지는 별개입니다.

나중에 확인한 이름은 [자료 추가·재개](data-contract.md#자료-추가와-재개)의 `update-ledger`로 새 ID만 추가합니다. 기존 이름·값·근거를 고쳐 쓰지 않습니다.
