# reference-v2 고정 구성

이 문서는 제작 입력용 고정 슬롯 규칙입니다. 검수 이미지·오류 위치·수정 정답을 읽는 경로가 아닙니다. 내용이 있는 단계는 `layout_profile:"reference-v2"`를 지정합니다.

현재 단계의 행만 확인합니다. 아래 순서와 개수를 유지하며 새 배치·구성요소를 만들지 않습니다.

공통 입력 계약에서 선택인 필드도 **reference-v2에서는 아래 조건이 필수**입니다.

- 모든 단계: `citation`에 사람이 읽는 짧은 출처를 빈 값 없이 씁니다. 단계·패널의 `source_ids`도 계약대로 연결합니다.
- 모든 `bullets`: 승인된 `icon`을 하나 지정합니다. actions 외의 글머리 패널에도 필요합니다.
- 모든 `flow`: `step_icons` 배열을 넣고 `steps`와 같은 개수·순서로 승인 아이콘을 지정합니다. 패널의 `icon` 하나로 대신하지 않습니다.
- actions의 모든 카드: `outcome`에 근거 있는 목적·결과를 빈 값 없이 씁니다.
- effects의 마지막 flow: `relationship:"sum"`을 넣고 두 비용 항목→합계의 정확히 3단계와 아이콘 3개를 채웁니다.

아이콘은 [입력 계약](data-contract.md#현재-단계와-패널)의 허용 목록에서만 고릅니다. 빈 문자열은 완성된 입력으로 인정하지 않습니다.

| 단계 | 패널의 고정 순서 | 필수 조건 |
|---|---|---|
| problem | `bullets → flow → bullets → bullets` (4개) | 근거 있는 현상·영향 관계만 표현 |
| cause | `bullets → table → bullets → flow` (4개) | 사실/가설 구분, 빈도 없는 비율 생성 금지 |
| actions | `bullets` 카드 3~6개 | 모든 카드에 승인된 `icon`과 근거 있는 `outcome` 필수 |
| effects | `metrics → table → flow` (3개) | 마지막 flow는 `relationship:"sum"`, 정확히 3단계인 두 항목→합계 |
| rollout | `table → flow → bullets` (3개) | 실적과 검토안 분리 |

effects 합계는 같은 통화·기간·단위의 원장 값만 사용합니다. 앞 두 수치 ID와 파생 합계의 `inputs` 순서가 같아야 합니다. 필요한 비용 자료가 없으면 지원 불가/자료 대기로 멈추며 숫자나 항목을 만들지 않습니다.

현재 단계 지침에 연결된 빈 입력 틀만 복사하고 키를 유지하며 업무 사실로 채웁니다. 빈 배열·문자열은 구조를 보여 주기 위한 것이므로 그대로 제작하지 않습니다. actions 틀의 카드 6개 중 실제 조치 수에 맞는 3~6개만 남기고 빈 카드를 채워 넣지 않습니다. rollout의 빈 `scope`는 근거에 따라 `actual` 또는 `proposal`로 선택합니다. 다른 단계 틀·완성 예시·검수 의견은 읽지 않습니다.

모든 문구·아이콘·결과는 [입력 계약](data-contract.md#현재-단계와-패널)의 근거·원장 검사를 따릅니다. 아이콘은 설명용이며 실제 사진·측정 증거가 아닙니다. 지원하지 않는 패널 수·kind·순서·긴 문구는 멈추고 자료 부족 또는 지원 범위를 보고합니다. 자동축소·새 좌표·소스 수정·즉석 대체 디자인으로 채우지 않습니다.

제작 중에는 동결된 스킬/라이브러리만 사용합니다. COM 검사 결과에 따른 허용 문구 단축·동일 입력 객체 복원과 소스/배치 변경을 구분하고, 별도 시각 평가의 정답은 받지 않습니다.
