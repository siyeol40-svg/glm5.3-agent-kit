# 사내 관측 결과에 따른 비시각 QA 경계

사용자가 전달한 사내 실행 보고를 반영한 기본 한계입니다. 이 개발 환경에서 같은 COM 결과를 재현한 것은 아닙니다. 다른 Office 버전/문서에서 값이 보인다고 이 환경의 미확인을 자동 해제하지 않습니다.

| 항목 | 허용하는 결론 | 금지하는 결론/대응 |
|---|---|---|
| 원본 변경 | 다시 읽은 COM-readable 객체·문구·속성의 비교 | metadata=내용 해시 또는 읽힌 속성 일치=문서 전체 동일; 보호 bytes/hash 접근 금지 |
| master/placeholder | 읽힌 객체의 실제 개수·값 | Layout_count=0이므로 상속 없음/전체 확인 완료라고 단정 금지; 상속 완전성 미확인 유지 |
| 글꼴·자동축소 | 지정된 nominal Size 및 읽힌 TextFrame/Bounds | AutoSize 값(1 포함)이나 Set_Size만으로 실제 축소 글자 크기/가독성 PASS 금지 |
| 사진 geometry/crop | 읽힌 프레임·crop 수치 비교 | 이미지 내용 동일성은 UNAVAILABLE; 새 자산 로그는 내용 의미 증명 아님 |
| 차트·OLE | 접근 가능한 외곽 객체·타입 | 계열/수치/OLE 내부를 읽었다고 주장 금지; 중요 내용이면 사용자 자료 확인 또는 승인된 native 도해/텍스트로 재구성 |
| 숨김 상태 | 현재 보고된 Slide.Hidden=null은 미확인 | null을 false/표시됨으로 변환 금지; 전체 페이지/비표시 콘텐츠 확인 완료 주장 금지 |

지원 text bounds 검사는 공간 초과를 탐지할 수 있지만 실제 렌더 잘림·가림·자동축소 크기까지 증명하지 않습니다. 기하 검사가 맞아도 명목 글자 크기와 실효 크기의 차이는 한계로 남깁니다.

검사 대상의 사실 데이터가 차트/OLE 내부에만 있고 읽을 수 없다면 해당 unit은 NEEDS_INPUT입니다. 값을 추정해 재제작하지 않습니다. 사용자가 내용을 확인해 제공하거나 재구성 대안을 명시적으로 허용해야 합니다. 승인 없는 기존 차트/사진 유지로 해결하지 않습니다.

숨김 상태는 문서 내용 누락/잔존 가능성의 잔여 위험입니다. 사용자에게 정상 PowerPoint UI에서 확인할 항목으로 남깁니다. 다른 API 경로가 있을 가능성과 현재 실제로 검증됐는지는 구분하며, 확인하지 않은 호출을 필수 단계로 넣지 않습니다.

미지원 속성을 무한 재시도하거나 모든 작업을 영구 차단하지 않습니다. 실제 제작에 필요한 사실/허가는 답변 전 차단하고, 구조적으로 관측 불가능한 검사는 미확인 한계로 보존하여 사용자 캡처/확인 단계에 넘깁니다. 전체 최종 상태는 USER_ACCEPTED_WITH_LIMITATIONS입니다.
